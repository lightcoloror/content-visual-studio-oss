# Review-chain candidate: four connected adapter modules

This candidate adds four first-party modules to the published 0.1.3 public
source and no other baseline behavior. It is a review proposal, not a release,
an installed-package acceptance or a human-approval/publication claim.

## Added modules

| Path | Role |
| --- | --- |
| `scripts/human_voice_review.py` | draft-only review bundle projection/application over the existing `human_voice_gate` |
| `scripts/cue_review.py` | cue-track validation, append-only decision events, immutable replay and revisions |
| `scripts/cue_timeline_adapter.py` | binds a reviewed cue revision to the unchanged Video Owner `audio_timeline.compose` |
| `scripts/video_timeline_dependency.py` | explicit, version- and hash-bound checked-source loader for the Video package |

Supporting first-party assets:

* `admin/review.html`, `admin/review.css`, `admin/review.js`, `admin/feedback.js`
  (existing local review page) and the packaged copies under
  `scripts/studio_assets/admin/`.
* `config/video-timeline-runtime.v1.lock.json` and the packaged copy under
  `scripts/studio_assets/config/`.
* `fixtures/minimal-review/` and `fixtures/minimal-cue-review/`: explicitly
  fictional synthetic review inputs, in source and packaged copies.
* `tests/test_human_voice_review.py`, `tests/test_cue_review.py`,
  `tests/test_video_timeline_dependency.py`, `tests/test_public_video_binding.py`,
  `tests/test_human_voice_review_js.cjs`, `tests/test_cue_review_js.cjs`,
  `tests/temp_workspace.py`.
* `pyproject.toml`: four `py-modules`, one script entry point, admin/fixture
  package data. No dependency, version or existing entry-point change.
* `README.md`: operator section for the new commands and roots.
* `docs/candidate-review-tests.md`, `docs/video-timeline-binding.md`: test and
  binding contracts.

## Per-module adaptations

The four modules are adapted from the supplied frozen first-party sources:
`human_voice_review.py` (frozen sha256 `7beee90f…`), `cue_review.py`
(`34a0fecf…`), `cue_timeline_adapter.py` (`5b9f6562…`),
`video_timeline_dependency.py` (`43a32c53…`). Functional contracts, error
strings, schemas, event/revision formats and fail-closed ordering are preserved.

### `human_voice_review.py`

* Adds a public, explicitly configurable review work root. `CONTENT_STUDIO_REVIEW_WORKSPACE`
  overrides it; otherwise the historical source-root default is used. In an
  installed layout the default is refused, so drafts, revisions, pages and media
  copies are never written into `site-packages/studio_assets`.
* `--allowed-root` continues to bound every source/artifact/media read; outputs
  are additionally bounded by the review work root. Both checks use resolved
  paths, so `..` and absolute escapes fail closed.
* Everything else is unchanged: bundle schema/version, digest canonicalization,
  candidate binding recomputation, immutable `bundle_sha256`, choice-span
  uniqueness, duplicate/overlap rejection, real-material read-only refusal,
  script-safe page embedding, exact-write revision persistence and the
  `built_pending_browser_validation` status.

### `cue_review.py`

* Decision commits resolve the same public review work root before writing.
* No change to the event schema, append-only history, head/parent checks,
  duplicate-id conflict handling, undo/redo semantics, writer lock, revision
  reconstruction or read-back tamper detection.

### `cue_timeline_adapter.py`

* Decisions, cache and output roots resolve through the configured review work
  root instead of a fixed workspace constant.
* Rendering still delegates to the unchanged `audio_timeline.compose`; the
  cache/output separation, byte budget, checked-source snapshotting, derived
  binding, receipt identity, runtime re-verification and quarantine behavior are
  preserved.

### `video_timeline_dependency.py`

* The reviewed lock resolves from `studio_paths.STUDIO_ROOT` (source tree or
  installed `studio_assets`), with `CONTENT_STUDIO_VIDEO_TIMELINE_LOCK` as an
  explicit override. This replaces a `__file__`-relative path that only worked
  in a source checkout.
* Unchanged: required explicit source root (no installed/checkout fallback),
  distribution/version check, exact file-set comparison, per-file SHA-256,
  symlink/junction escape refusal, `importlib` checked-source loader with
  `dont_inherit=True`, pre-import rejection, import-origin verification and
  in-flight drift re-verification.

## Lock provenance

The supplied earlier reference lock was **not** copied: it declared a different
git head and did not match the supplied fixed public-Video bytes (34 missing,
21 extra, 55 changed entries in the compared file set). The shipped lock was
regenerated by hashing the actual supplied `pyproject.toml` plus the complete
`src/video_creation_pipeline` file set (182 entries). Its provenance names the
declared fixed commit and states that the per-file bytes are authoritative; it
does not claim an unverified git HEAD contains them. See
`docs/video-timeline-binding.md`.

## Preserved boundaries

* No new platform, database, router, renderer, owner, queue or approval system.
* No copied Video runtime, font, image, music, model, browser or FFmpeg binary.
* Draft-only: every status is `synthetic_draft_only` /
  `complete_draft_only` / `built_pending_browser_validation`; no human approval
  or publication authorization is created.
* Existing `human_voice_gate`, `studio_paths` and all other baseline files are
  unchanged.
* The optional `feedback.js` backend is not implemented here; the page is not
  evidence of feedback service availability or browser acceptance.
